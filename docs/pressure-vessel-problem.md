# Pressure vessel design problem

The pressure vessel design problem is a widely used constrained engineering optimization benchmark. It seeks low-cost vessel dimensions while satisfying material thickness, volume, and geometric constraints.

Typical decision variables include shell thickness, head thickness, inner radius, and cylindrical-section length. A common formulation combines material, forming, and welding cost terms, subject to thickness relationships and a minimum-volume requirement. Some variants treat thickness as discrete; others use continuous relaxations.

For reproducibility, a study should state the exact objective, units, constraint handling method, variable domains, and whether thickness variables are discrete. Results from differently formulated variants should not be compared as if they were identical.
